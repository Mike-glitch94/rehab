# リハビリノート

理学療法などで受けたフィードバックと、自宅でやるリハビリを記録するWebアプリ（PWA）です。
データは端末のブラウザ内にのみ保存され、サーバーには送信されません。

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成（例：`rehab-notes`）。
2. このフォルダの中身（`index.html` `manifest.webmanifest` `sw.js` `*.png` `README.md`）を、リポジトリの直下にアップロード。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
4. 数分後、`https://<ユーザー名>.github.io/rehab-notes/` で開けます。

> 公開リポジトリだと、アプリのコードは誰でも見られます。記録そのものはあなたの端末内にしかないので、見られることはありません。

## iPhoneのホーム画面に追加する
1. **Safari** で上のURLを開く。
2. 共有ボタン → **ホーム画面に追加**。
3. **ホーム画面のアイコンから起動して**記録を始める。

### 注意：保存先はSafariとホーム画面アプリで別
iPhoneでは、Safariで入力したデータはホーム画面アプリに引き継がれません。
先にホーム画面に追加してから、アプリ側で記録してください。
すでにSafariで記録している場合は、Safariで「バックアップ」からテキストをコピーし、ホーム画面アプリの「バックアップ」→「復元」に貼り付けると移せます。

## バックアップ
「バックアップ」タブから書き出せます。30日以上取っていないと警告が出ます。
